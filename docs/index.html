Path Tracker

Organize goals into steps and concrete tasks.

About the App

Path Tracker is a local-first app for structured goals. Keep each goal readable, break it into steps, and track the tasks that move it forward.

Features

  • Track multiple goals
  • Break each goal into steps
  • Write long-form task descriptions
  • Mark tasks complete without hiding them
  • Review progress in a read-only archive

Additional Information

This app is under active redesign as a general-purpose personal progress tracker.

Feedback and suggestions are welcome through the project repository.
